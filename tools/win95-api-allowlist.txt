# Windows 95 import allowlist for PhotoCraft Classic executables.
#
# One `DLL!Function` per line ('#' starts a comment).  tools/check_imports.py
# fails the build if PhotoCraftClassic.exe, PCUpdate.exe or Setup.exe import
# anything that is not listed here.
#
# CURATED BY HAND from Windows 95-era SDK documentation ("Requires Windows
# 95 or later" / Win32 API reference of the period) and the export lists of
# the retail Windows 95 system DLLs as documented then; it is NOT
# machine-verified against a real Windows 95 installation.  When in doubt a
# function was left out.  Anything newer must be reached through
# LoadLibrary/GetProcAddress with a fallback (the updater does this for
# wsock32, CryptGenRandom, RtlGenRandom, GetOpenFileNameA and
# SetThemeAppProperties), which this checker cannot see.
#
# Scope: KERNEL32/USER32/GDI32 (ANSI functions present in Windows 95 retail),
# ADVAPI32 registry functions (the security API is NT-only), WSOCK32
# (Winsock 1.1), VERSION, and Windows 95 SHELL32/COMDLG32/WINSPOOL.
# Deliberately absent (newer than Windows 95 retail): CryptGenRandom,
# IsDebuggerPresent, GetFileAttributesExA, GetFileSizeEx, GetLongPathNameA,
# TrackMouseEvent, GetAncestor, MonitorFromWindow, GetMonitorInfoA,
# AnimateWindow, SetLayeredWindowAttributes, GradientFill, AlphaBlend,
# SHGetFolderPathA, SHGetSpecialFolderPathA, GetDefaultPrinterA, anything
# from WININET/WINHTTP/WS2_32/MSVCRT/UXTHEME/COMCTL32 v6.
